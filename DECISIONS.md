| 2026-11-04 | F2a | Moyasar webhook verification | Docs (`/api/other/webhooks/webhook-reference`, `/guides/dashboard/setting-up-webhooks`, `available-webhooks`, `create-webhook`): the body is `{id, type, created_at, secret_token, account_name, live, data}` where `data` is the payment; the **secret token is a shared secret in the JSON body**, no signature header or HMAC is documented.
